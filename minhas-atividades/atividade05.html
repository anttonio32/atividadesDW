Semelhanças

  • Quase todos os back-ends seguem a ideia de receber uma requisição HTTP, processar e devolver uma resposta (HTML ou JSON).
  • Django, Laravel, Spring Boot, ASP.NET Core e Rails usam padrões parecidos: rotas, controladores, modelos e acesso a banco por ORM.
  • React, Vue e Angular dividem a tela em componentes reutilizáveis.
  • Todos conversam com bancos relacionais, e vários com bancos não relacionais.

Diferenças

  • Lado de execução: React, Vue e Angular rodam no navegador; PHP, Python, Java, C# e Ruby rodam no servidor; Node.js leva o JavaScript para o servidor.
  • Tipagem: Java, C# e TypeScript são tipados de forma estática; PHP, Python, Ruby e JavaScript são dinâmicos.
  • Filosofia: Django, Rails e Angular trazem muita coisa pronta e impõem estrutura; Flask, Express e React deixam mais escolhas para quem programa.
  • Hospedagem: PHP roda em quase qualquer plano compartilhado barato; Java, C# e Node pedem servidor próprio ou nuvem.
