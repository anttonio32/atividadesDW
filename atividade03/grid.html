Atividade 03 · Grid

Exercício 2: montar layouts em CSS Grid. Em cada exemplo, o resultado está acima do código.

1. Colunas iguais

repeat(3, 1fr) cria três colunas que dividem a largura por igual.

.grade { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; }

2. Áreas nomeadas

Com grid-template-areas o layout fica desenhado no próprio CSS.

topo
menu
texto
rodapé
.pagina {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "topo   topo"
    "menu   texto"
    "rodape rodape";
  gap: 8px;
}
.topo   { grid-area: topo; }
.menu   { grid-area: menu; }
.texto  { grid-area: texto; }
.rodape { grid-area: rodape; }
